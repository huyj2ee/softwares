4.2.1.1 Signin use case

Test case BESignin01
  • Pre-Condition: a user with username “admin” and password “root” assigned role “admin” is created by executing test case BECreateUser01 and test case BEAssignRole01.
  • Description: Check response when valid username and password is entered for admin role account that is enabled and not locked.
  • Test data:
    • Username: admin
    • Password: root
  • Test steps:
    • Select  POST method.
    • Enter url: http://localhost:8080/jwt/v1/signin
    • Select Body tab:
      • Select raw option.
      • Select JSON format.
      • Enter body data:

  

{
  "username": "admin",
  "password": "root"
}

 

  • Click Send.
  • Expected result: Response section has data as below:
    • Status: 200 OK
    • Body:
      • Format: JSON
      • Content: a JSON string with “accessToken” and “refreshToken” properties.
